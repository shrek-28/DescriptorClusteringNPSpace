# Large Scale Clustering of Natural Product Chemical Space

This GitHub repository contains the associated data, plots and scripts for the paper - [Mapping Chemical Diversity: Descriptor-Guided Clustering of Natural Products in the COCONUT Database](https://doi.org/10.64898/2026.06.03.729746 )

G Shreyasree, Adithya Dileep, Akhileshwar Namani and Prashantha Karunakar

# Folder Structure 
<ol>
<li> Data </li>
<ul>
<li> <strong>cluster_profiling </strong>: contains data related to representative analysis, Bland-Altman summary analyses, and chemical, geometric, fidelity and compactness analysis of clusters </li>
<li> <strong>clustering_try_results </strong>: contains results of use of 3 clustering techniques on sample dataset of 50,000 molecules </li>
<li> <strong>complete_correlation_matrix </strong>: contains data related to complete correlation analysis of the dataset</li>
<li> <strong>Descriptor_Data </strong>: contains details of descriptor values for all molecules in chunks, separated by category </li>
<li> <strong>flat_files </strong>: contains details of individual pairwise correlations falling within the given correlation threshold ranges</li>
<li> <strong>full_clustering </strong>: details of full cluster profiles along with UMAP and HDBSCAN core assignments, along with stratfied analyses</li>
<li> <strong>hierarchical_clustering_dist_matrices </strong>: distance matrices from usage of hierarchical clustering for descriptor selection</li>
<li> <strong> Identifier_SMILES_Data</strong>: contains details of SMILES and identifier of all compounds in COCONUT database </li>
<li> <strong> method_analysis</strong>: contains details of analysis of descriptor selection by different selection strategies, threshold ranges and descriptor counts </li>
<li> <strong> methods</strong>: contains data of correlation matrices and descriptors selected by different selection strategies, threshold ranges and descriptor counts </li>
<li> <strong> pareto_optimization </strong>: contains data generated by Pareto-front optimization analysis </li>
<li> <strong> pca_data</strong>: data generated by PCA on all 80 and 20 selected descriptors </li>
<li> <strong> perturbation_data </strong>: data generated by 60/40 splits on the complete data using 5 different random seeds </li>
<li> <strong> random_molecule_docking_results</strong>: results of docking of 25 random molecules selected from each cluster  </li>
<li> <strong> representative_analytics </strong>: analysis of docking of representative molecules and their scores </li>
<li> <strong> representative_docking_results_files</strong>: docking results of 7 types of representatives from selected clusters </li>
<li> <strong> scaffold_decomposition </strong>: scaffold decomposition results of the complete COCONUT database</li>
</ul>
<li> Plots </li>
<li> <strong> cluster_profile_analysis </strong>: distribution and association analyses of cluster properties </li>
<li> <strong> clustering_try_result_analysis </strong>: plots that analyse results of clustering of the 50k dataset using different methods </li>
<li> <strong> complete_correl_matrix </strong>: plots generated on complete correlation matrix  </li>
<li> <strong> descriptor_presence_plots</strong>: analysis of descriptor presence across correlation threshold ranges, descriptor counts and selection strategies </li>
<li> <strong> descriptor_wise_method_analysis </strong>: analysis of descriptor type enrichemnt across correlation threshold ranges, descriptor counts and selection strategies </li>
<li> <strong> greedy_max_coverage</strong>: correlation matrices of descriptor selection done using greedy maximum coverage </li>
<li> <strong> hierarchical_clustering </strong>: correlation matrices of descriptor selection done using both hierarchical clustering methods</li>
<li> <strong> hierarchical_clustering_dendrograms</strong>: dendrograms generated using clusters generated by hierarchical clustering techniques </li>
<li> <strong> method_comparison</strong>: Jaccard similarity comparison plots on varying selection strategies, correlation threshold ranges and descriptor counts</li>
<li> <strong> pareto_optimization</strong>: Figures generated for pareto optimization analysis </li>
<li> <strong> pca</strong>: Figures generated for analysis of PCA results </li>
<li> <strong> perturbation_analysis</strong>: correlation matrices of descriptors generated by perturbation-based analysis</li>
<li> <strong> representative_analyses</strong>: docking-score based analysis on selected representative molecules</li>
<li> <strong> scaffold_decomposition</strong>: results of analysis scaffold decomposition of the dataset </li>
<li> Scripts </li>
</ol>
